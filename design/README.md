## 1.3 Ключевой сценарий записи (`14:288`)

Бизнес-логика из ТЗ. Каждый шаг можно начать с середины: со страницы врача, услуги или акции.

01 Что беспокоит / направление → 02 Услуга и цена → 03 Врач → 04 Дата и время → 05 Имя и телефон → 06 Заявка → администратор → 07 Подтверждение SMS / email → 08 Напоминание о приёме

**Короткие пути**
- «Не знаю, к какому врачу» → бесплатный звонок-консультация администратора / заявка без выбора врача.
- Карточка врача → «Записаться» с уже выбранным врачом.
- Услуга / акция / Check-up → запись с уже выбранной услугой.

**Правила формы**
- Минимум полей: имя, телефон (+998), согласие на обработку данных.
- Выбор времени — только свободные слоты.
- После отправки — экран «Заявка принята» с датой, врачом, адресом и что взять с собой; не «тишина».
- Ошибки — рядом с полем, без обвинений, введённые данные сохраняются.

**Уведомления (ТЗ)**
- Пациенту: подтверждение, напоминание, изменение, отмена, готовность результатов.
- Клинике: новая заявка, запись, отмена, изменение.
- Каналы: SMS, email, push.
